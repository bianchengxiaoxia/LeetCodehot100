# 438. 找到字符串中所有字母异位词 · 解题思路与收获

## 思路（定长窗口 + 计数指纹）

- `need` = p 的 26 格计数板；`win` = 当前窗口的计数板
- 窗口每滑一格**增量维护**：右端进字符 `+1`，滑出的 `s[i-n2]` 字符 `-1`——绝不全量重算
- 窗口铺满（`i >= n2-1`）且 `win == need` 时记录左端下标 `i-n2+1`
- 时间 O(26·n)，空间 O(26)——常数即 O(1)

## ⭐ 核心收获：数组指纹——用"可比较的统计状态"代替"原始内容"

- 两个字符串**组成相同** ⇔ 26 格计数板相同。比较两块板，等价于比较两串的所有排列，但成本 O(26) vs O(k log k)
- 关键语言特性：**`list == list` 是逐元素值比较**（`[1,2,3] == [1,2,3]` 为 True，比较的是内容不是地址；`is` 才是比较身份）——所以两块计数板可以直接 `==`
- 数组指纹的两次出场，要求不同、形态不同：
  - **49. 字母异位词分组**：指纹要进字典当 key → 必须可哈希 → `tuple(cnt)`
  - **438 本题**：指纹只用来比较，不进字典 → 列表直接 `win == need`
- 泛化：指纹不一定是计数——**任何"把大状态压缩成小而可比较的对象"的思路都是指纹**。排序串也是指纹（我的第一版），但计数板能增量维护（±1），排序每窗重算——**可维护性才是指纹选型的决定因素**

## 滑动窗口第二课：状态容器升级

| 题 | 窗口状态 | 冲突处理 | 状态更新 |
|----|----------|----------|----------|
| 3. 无重复最长子串 | set（在/不在）| 左边界吐到重复消失 | add / discard |
| 438. 异位词 | 计数板（各有几个）| 无冲突，定长滑动 | +1 / −1 |

两题同一个灵魂：**滑动 = 增量更新（每步只动 2 个字符），绝不为窗口重算全量**。我的对照版每窗 `join(sorted(...))` 全量重排，功能对但 O(n·m·log m) 超时——全量重算与增量维护，就是 TLE 与 AC 的分界线。

## 语法坑：括号三兄弟 + 不可变字符串（本题主打校对事故）

1. **str 不可变**：没有 `.sort()`；字符串排序惯用法 `''.join(sorted(s))`
2. **切片冒号 ≠ 元组逗号**：`s[left:right]` 是切片，`s[left,right]` 是拿元组当下标 → TypeError
3. **圆括号 = 调用动作，方括号 = 取下标**：`ord('a')`、`append(x)` 是动作；`ord['a']`、`append[...]` 全崩——同一文件里我一会儿写对一会儿写错，纯属校对缺失
4. `for` 行忘写冒号
5. 修正认知：`win == need` 是 O(26) 次比较（说"常数 O(1)"没错，面试说 O(26) 更精确）；计数板是"记个数"，不是"标 1"

## 自测纪律（照妖镜用例组）

- `'cbaebabacd','abc'` → `[0, 6]`（基本功能）
- `'aa','bb'` → `[]`（无解）
- `n2 > n1` → `[]`（边界，进不了窗口）
