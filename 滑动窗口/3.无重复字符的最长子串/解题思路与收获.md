# 3. 无重复字符的最长子串 · 解题思路与收获

## 思路

- 滑动窗口：`right` 逐格探路，`left` 被重复逼着右移；不变量——窗口 `[left, right]` 内**永远无重复**
- 撞重复 → 左边界逐个吐字符直到重复消失；收编新字符；每轮结算 `right - left + 1`
- 时间 O(n)（每个字符最多进窗口一次、出窗口一次——又是均摊），空间 O(字符集)

```python
for right in range(n):
    while s[right] in windows:        # 冲突：左边界滑动
        windows.discard(s[left]); left += 1
    windows.add(s[right])
    result = max(result, right - left + 1)
```

## 收获

### 1. 滑动窗口（本专题核心武器）

- **本质是快慢指针的同向版**：right = fast（探路），left = slow（划界），窗口 = 两指针夹住的区间——283 移动零的功底直接迁移
- **不变式思维**再次立功："窗口内无重复"这个承诺，循环每一步都在维护
- **适用信号**："最长/最短的**连续**子串或子数组，满足某种约束"（无重复、和 ≥ target、至多 k 种字符……）
- **滑动 ≠ 推倒重来**：撞重复时，正确的新起点是"上一个相同字符的下一位"，中间的字符仍然有效。我第一版 `clear()` 全清，把 `"abac"` 的 `"bac"` 丢了——**clear 是绕路信号**

### 2. 集合删除三兄弟：discard / remove / pop

| 写法 | 语义 | 元素不存在时 |
|------|------|--------------|
| `s.discard(x)` | 指定请出 x | **不报错**（刷题安全牌）|
| `s.remove(x)` | 指定请出 x | KeyError |
| `s.pop()` | **不收参数**，随机弹出一个 | 空集合 KeyError |

- 集合的 pop 之所以"随机"，是因为集合**无序**——没有位置的概念；要"指定弹出一个"就用 discard/remove
- 同名不同义对照：`list.pop(i)` 按位置、`dict.pop(key)` 按 key、`set.pop()` 什么都不按

## 教训

1. **条件性 bug**（本周第三起）：`windows.pop(s[left])` 写错只在"撞重复"分支才触发——无重复字符串全绿，一重复就崩。**自测纪律：每条分支至少被一个用例踩过**（`aa` 一上来就重复 / `abba` 连吐多个 / `abc` 从不进 while / `""` 空串）
2. `len(str)` → TypeError：`str` 是内置类型本身，参数叫 `s`——变量名手滑系列（同款：三数之和的 `range(n)`）
3. 窗口长度 = **下标差 + 1**（数元素个数），容器宽度 = 下标差（数柱子间距）——两套公式别打架
