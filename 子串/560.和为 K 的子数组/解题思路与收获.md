# 560. 和为 K 的子数组 · 解题思路与收获

## 思路（前缀和 + 哈希）

- 核心恒等式：**子数组和 = 两个前缀和之差**
- 要 `s_new - s_old == k` ⇔ `s_old == s_new - k`——于是"扫所有旧前缀"降级为字典 O(1) 查询
- 字典 `count` 记录每个前缀和出现过的次数；遍历中**先查询后登记**
- 两个易漏细节：`{0: 1}` 哨兵（空前缀，覆盖从下标 0 开始的子数组）；先查后登（k=0 时不会把自己配给自己）
- 时间 O(n)，空间 O(n)

## ⭐ 核心收获：前缀和 × 哈希——"区间和问题"的万能组合

两个旧武器的化学反应：

- **前缀和**负责变形：把"一段区间的和"变成"两个前缀值的差"（区间问题 → 两数配对问题）
- **哈希表**负责配对：遍历时问档案柜"我的搭档 `s - k` 出现过几次"——**这正是两数之和的内核**，第一题的武器在第十题回归，闭环了

**识别信号**：题目问"子数组/子串的和满足某条件"（等于 k、出现几次、最长最短）——尤其当**数组含负数**时（有负数 ⇒ 和不单调 ⇒ 滑动窗口失灵，前缀和+哈希接棒）。

**演化路线**（同一对武器的三种打法）：

| 题型 | 字典里存什么 |
|------|--------------|
| 和为 k 的子数组有几个（本题）| 前缀和 → 出现次数 |
| 最长的和为 k 子数组 | 前缀和 → **最早**出现位置 |
| 最短的和为 k 子数组 | 前缀和 → **最晚**出现位置 |

## 教训

1. **前缀和下标约定要成对记**：`presum` 长 n+1、`presum[0]=0` 哨兵 ⇒ 填表配 `nums[i-1]`——我崩在 `nums[i]` 越界
2. **思路对 ≠ 能过**：O(n²) 的双重循环版功能全对，但 n=2 万实测 10.6 秒必超时——正确解也要对数据规模敏感
3. **循环头和身体要配套**：`for i in range(len(nums))` 的身体里写 `s += x` → NameError（x 是上一版元素遍历的残留）
4. `d.get(key, default)` 正式上岗：安全取值三件套 `get` / `setdefault` / `in`
5. 只需要当前前缀和时，用滚动变量 `s` 而不是整个 `presum` 数组——本题标准解连数组都不用建

## 语法与自测

- 照妖镜用例：`[1,1,1],k=2 → 2`（基本）、`[0,0,0],k=0 → 6`（专查先查后登的顺序）、`[1,2,3],k=3 → 2`
- 注释心法沉淀：代码说"做什么"，注释说"为什么"和"怎么想到的"；推导链 > 结论；踩过的坑写进注释
