# 128. 最长连续序列 · 解题思路与收获

## 思路

- 题型识别：数组顺序不定，求"数值上连续"的最长段 → 不排序，上哈希集合
- `s = set(nums)`，只从**链头**开始数：`x - 1 not in s` 说明 x 前面没人，才是链头
- 从链头沿 `x+1, x+2, ...` 探测；每条链只被完整走一次 → 均摊 O(n)
- 对比排序法：O(n log n) 能 AC 但不满足进阶的 O(n)，面试要能口头讲清这个演进

## 收获

1. **set 也是哈希家族**——只存 key、不存 value 的字典，`x in s` 是 O(1)。"顺序不定 + 查存在性/找连续段"这类题，第一反应建 set
2. **双层循环 ≠ 一定 O(n²)**：外层找链头 + 内层沿链数，均摊下来每个数最多被摸两次，总工作量还是 O(n)。判复杂度要算总工作量，不能只数循环嵌套了几层
3. **遍历集合而不是列表**：set 的去重本身是算法正确性的一部分。`for x in nums` 时，重复出现的链头会把整条链反复走，数据重复度高时直接超时（实测 2000 倍差距，一字之差）
4. **本地通过 ≠ 提交通过**：遇到"本地好好的、提交超时"，第一反应是 diff 提交版和手头版代码，而不是先怀疑算法

## 关联

- 与两数之和、字母异位词分组一脉相承：都是"遍历 + 查哈希档案柜"。本题查的是"搭档数值存不存在"——只需要存在性、不需要映射值，所以用 set 而非 dict
