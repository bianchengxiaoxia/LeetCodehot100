# 42. 接雨水 · 解题思路与收获

## 思路（逐柱模型 + 预处理）

- 每根柱子独立计算：`存水 = min(左边最高, 右边最高) - height[i]`
- "最高"定义**含自身** → `min ≥ height[i]` 恒成立，天然免判负数
- 左右最高用两次递推预处理（前缀最大 / 后缀最大），再一遍求和
- 时间 O(n)，空间 O(n)

## ⭐ 最大收获：可递推的预处理数组（前缀/后缀聚合）

**核心思想**：如果每个位置都要问"从起点到我的某种汇总信息"，不要每个位置重扫一遍（O(n²)），而是预计算一张表——相邻位置的答案只差一个元素，可以递推：

```
agg[i] = f(agg[i-1], a[i])
```

| 家族成员 | 递推式 | 典型题 |
|----------|--------|--------|
| **前缀和** | `prefix[i] = prefix[i-1] + a[i]` | 560. 和为 K 的子数组（下一专题见！）|
| **前缀最大**（本题） | `left_max[i] = max(left_max[i-1], a[i])` | 接雨水 |
| 后缀版 | 从右往左扫，看 `i+1` | 接雨水 |

**识别信号**：题目要求"对每个 i，知道它左边/右边的某种汇总（最大/和/乘积）"——就是预处理表登场的时候。

**三个好处**：① O(n²)→O(n)；② 把分类讨论变成统一公式（逐段法要讨论孤峰/平底，逐柱法一个公式通吃）；③ 为进一步优化（双指针 O(1) 空间）铺路——先有"要维护什么信息"的清晰模型，才压缩得动。

**术语辨析**：前缀**和**（加和）≠ 前缀**最大**（取 max），是同一家族的两个工具。注释和口头都要说准。

## 本题的教训

1. **递推式写错变量**：`max(left_max[i], left_max[i-1])`（✗）vs `max(height[i], left_max[i-1])`（✓）——前者因初始值 0 退化成"复制首元素"。写完递推要**逐字读语义**："我的聚合 = f(我的值, 邻居的聚合)"
2. **复合退出条件的循环**（`while fast < n and ...`）退出后，先分辨是哪个条件命中，再碰下标——自己的逐段法崩在 `height[n]` 越界
3. **自己的逐段填充法只覆盖了一半世界**：只处理了"右墙 ≥ 左墙"的段，孤峰段（水位由右墙决定）漏算——分类讨论必须穷尽所有形态；镜像第二遍可补全（留作加餐）
4. `[3,0,3]` 蒙对不代表对——对拍要覆盖"水位由左墙定 / 由右墙定 / 首尾即高墙"各种形态
