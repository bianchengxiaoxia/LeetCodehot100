# 283. 移动零 · 解题思路与收获

## 思路

- 关键约束：**原地** + **保持非零元素相对顺序** → 快慢指针
- `slow` 指向"下一个非零数应该放的位置"，`fast` 逐个扫描
- `fast` 遇到非零数就和 `slow` 位置交换，`slow` 前进；遇到零什么都不做（零自然留在后面）

```python
slow = 0
for fast in range(len(nums)):
    if nums[fast] != 0:
        nums[slow], nums[fast] = nums[fast], nums[slow]
        slow += 1
```

## 收获：快慢指针的精髓

1. **同向双指针把数组切成三段**，这是理解一切快慢指针题的地图：

   ```
   [0, slow)          [slow, fast)      [fast, ...)
   已处理好的合格区     已扫过的"废料区"    还没扫描的区
   （非零、保序）       （放的是零/不要的）
   ```

2. **慢指针不是"位置"，是"边界"**：它左边永远是合格产品。它不自己找数据，只负责"接收"；找数据的活全归快指针。想到快慢指针，先问"slow 左边承诺了什么"。

3. **不变式思维**：写双指针代码前先用一句话说清"任何时刻，两个指针各自划分的区域是什么"，循环的每一步都要维护这个约定——约定不破，循环结束答案自然正确。这次的不变式：`[0, slow)` 全是非零且保持原始相对顺序。

4. **这是"数组原地整理"的万能模板**：27.移除元素、26.删除有序数组中的重复项，都是同一件衣服换扣子——slow 左边放"要留下的"，fast 负责扫描供货。

## 语法与教训

- `a, b = b, a`：Python 元组交换，两行换一行，不需要临时变量
- **循环条件一律写 `<`，不写 `!=`**：指针一旦越过终点，`!=` 会变死循环
- 第一次自己写的版本崩在 `nums += 1`（想写 `end += 1`）——**指针推进的对象要盯准**；以及内层搜索要带边界保护，否则全零数组直接越界
