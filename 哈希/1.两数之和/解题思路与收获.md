for i ,x  in enumerate()  这个函数
enumerate 是 Python 的内置函数，作用是在遍历一个序列时，同时拿到“下标”和“元素”——它把“自己维护计数器”这件事代劳了
它把序列包装成一个“逐个产出 (下标, 元素) 元组”的迭代器。在 for 循环里写 for i, x in enumerate(nums)，其实是元组解包：每轮拿到一个 (0, 'a') 这样的元组，拆成 i = 0、x = 'a'——和我们在python基础里学的 i, j = ... 解包是同一回事（只不过右边是可迭代的）。

tips :
start 参数：下标不从 0 开始

for i, x in enumerate(["a", "b", "c"], start=1):
    print(i, x)
